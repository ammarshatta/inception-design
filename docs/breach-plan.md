# Data breach plan (draft — the owner's lawyer confirms)

Egypt PDPL 151/2020: notify the Personal Data Protection Center within **72 hours** of knowing, and the affected people soon after.

| Step | Who | When |
|---|---|---|
| Contain: rotate the admin password and API keys, revoke share links, disable the affected users | Owner / technical contact | immediately |
| Preserve evidence: keep server logs, `Access Log`, `Error Log`, and the last backups | Technical contact | first hours |
| Assess: which personal data (see `data-register.md`), how many people, what risk | Owner + DPO (if appointed) | within 24 h |
| Notify the regulator | Owner / DPO | within 72 h |
| Notify affected clients in Arabic (what happened, what we did, what they should do) | Owner | right after |
| Fix and record: cause, fix, lessons, in this file's log | Technical contact | within 2 weeks |

Contacts: _owner to fill_ (owner, technical contact, lawyer, DPO).
