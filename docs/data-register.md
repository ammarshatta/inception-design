# Register of processing (draft — the owner's lawyer confirms the purposes and retention)

| Data | People | Where | Why | Kept for |
|---|---|---|---|---|
| Name, mobile, email, username | clients, engineers, foremen, subcontractors | User, Contact, Customer | accounts, notices, signing codes | while the account is active + _lawyer_ |
| Project address and site coordinates | clients | Project | site work, geofence | project + _lawyer_ |
| Site photos and videos (EXIF/GPS removed) | clients' homes | private files | progress records | project + _lawyer_ |
| Signatures, signing IP and time, signed PDFs with hashes | clients, subcontractors | Signature Request | contract evidence | per contract law |
| Clock-in location (only at clock-in/out, after consent) | workers | Clock Event | trusted hours | _lawyer_ |
| Payments and invoices | clients | ERPNext accounting | accounting | per tax law |
| Bank-transfer receipt photos | clients | private files | payment proof | per tax law |
| Chat messages | clients, staff | Project Message | project communication | project + _lawyer_ |
| Leads from the public site (name, mobile, area, governorate) | prospects | Lead | sales follow-up | _lawyer_ |
| Push subscriptions (browser endpoint) | portal users | Push Subscription | notifications | until unsubscribed |
| AI conversations (if switched on) | staff | AI Conversation | assistant history | _lawyer_ |

Card data is never stored (the gateway handles it). Passwords, OTPs and gateway secrets are never logged.
